# LudmilaRojo Studio & Ebers — Sitio Web Oficial

Sitio web institucional y plataforma de contacto para Ludmila Rojo Studio & Ebers, enfocado en la evaluación postural, análisis digital de la pisada y confección de plantillas biomecánicas personalizadas mediante tecnología Ebers.

##  Características
* **Presentación de Servicios:** Información detallada sobre estudio baropodométrico, diseño de plantillas personalizadas y atención kinésica integral.
* **Canales de Contacto:** Integración de formulario de consultas.
* **Sección Multimedia:** Contenedor de video explicativo integrado desde YouTube para mostrar el proceso de evaluación.
